# CHS BACON Website
This is the website for the Best All Around Club of Nerds (BACON)! BACON is a STEM club at Charlottesville High School with various subgroups that engage in independently directed activities. Some of these activities include: robotics, environmental activism, electronics design (PCBs, etc.), game development, and model rocket launching.
